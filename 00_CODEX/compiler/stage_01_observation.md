# Stage 01: Observation

## Purpose

Describe evidence.

Observation records what exists in the evidence corpus without interpretation, synthesis, evaluation, or application. This stage makes evidence findable, traceable, and auditable while preserving evidence as immutable source material.

## Evidence Examples

- Report
- Interview
- Dataset
- Financial report
- Survey
- Academic paper
- Government publication
- Industry report

## Allowed Work

- Identify files and source records.
- Record filenames, paths, file types, sizes, checksums, dates, and available metadata.
- Note source status and basic file role.
- Preserve provenance.
- Flag missing metadata or review needs.

## Prohibited Work

- Do not interpret meaning.
- Do not classify topics beyond observable metadata.
- Do not extract concepts.
- Do not modify source evidence.
- Do not create canonical knowledge objects.

## Outputs

- Inventory
- Metadata
- Manifest
- Duplicate or review reports

## Compiler Questions

- What evidence changed?
- What new evidence appeared?
- What evidence metadata changed?
- What evidence requires review before classification?

## Exit Criteria

Evidence is inventoried, uniquely identifiable, and ready for filename-, metadata-, or content-based classification.
